Dark web IP scanner and enrichment tool

The problem. Cross-checking a suspicious IP across reputation engines slowed investigations down.

The build. A Python script that queries VirusTotal, AbuseIPDB, AlienVault OTX and dark-web OSINT feeds, then returns geolocation and a severity score in one analyst-ready summary.

Python, REST APIs, OSINT

SIEM log processing engine

The problem. Unparsed raw logs flooded the console, caused alert fatigue and raised mean time to investigate.

The build. Custom Python parsers pull IP, user and payload fields out of raw logs, pass structured output into SIEM workflows and flag brute-force patterns automatically. Triage got 30% faster.

Python, regex, SIEM integration

AI-assisted phishing detection engine

The problem. Standard email gateways miss convincing phishing and zero-day malicious URLs.

The build. A Python app scans mail over IMAP, validates SPF, DKIM and DMARC, checks URLs against CTI feeds, adds contextual AI analysis, and quarantines what it flags.

Python, IMAP, Gemini API, email forensics

Zero-trust BYOD security framework

The problem. Unmanaged personal devices create serious access risk in corporate networks.

The build. A zero-trust access framework using AES-128 encryption and UUID-based device authorisation, with Isolation Forest models and CNN facial recognition to flag anomalies. This was my final-year project.

Python, machine learning, zero-trust

Kali Linux pentesting scanner

The problem. Routine assessments meant running fragmented tools by hand and delaying the report.

The build. A Bash CLI that runs Nmap stealth scans, Nikto web probes and Metasploit auxiliary modules in one command, then consolidates everything into an HTML report. Assessments ran twice as fast.

Bash, Kali Linux, Nmap, Nikto, Metasploit
